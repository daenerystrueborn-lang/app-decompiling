# Website Integration Guide (`anime-stream-dl-sdk`)

This guide shows how to integrate **MiruDL** and **AniFam** streaming + concurrent downloading into any website (Node/Express/Next.js backend + browser frontend).

---

## 1. Quick Start (Standalone Server + Demo UI)

```bash
cp .env.example .env
# Edit PROXY_SECRET and optional ANIFAM_BEARER_TOKEN
npm start
```

Open `http://localhost:3000/` in a browser:
- Switch between **AniFam (3-Mode)** and **MiruDL (AniLab + Kyoto)**.
- Search any anime, pick an episode, switch servers (`AniFam`, `Backup Server 1`, `[Web]` embed), test Intro/Outro Skip cues, and trigger either **Download via Server Stream (`.mp4`)** or **Download in Browser (Live Progress)**.

## 2. Backend Integration (Node.js / Express / Next.js)

### Option A: Mount `createAppServer()` directly

```js
import { createAppServer } from 'anime-stream-dl-sdk';

const { server } = createAppServer();
server.listen(3000, '0.0.0.0');
```

### Option B: Use the SDK modules inside your existing API routes

```js
import {
  MiruDLClient,
  AniFamClient,
  AniFamPlaybackController,
  MediaProxy,
  createHlsDownloadStream,
} from 'anime-stream-dl-sdk';

const mirudl = new MiruDLClient();
const anifam = new AniFamClient({ bearerToken: process.env.ANIFAM_BEARER_TOKEN });
const proxy = new MediaProxy({ secret: process.env.PROXY_SECRET });
```

1. **Resolve Playback on the Server** (keeps Kyoto HMAC keys & `Bearer` tokens off the client):
   - MiruDL: `await mirudl.resolvePlayback(episodeId, { language: 'jpn', preferredQuality: '1080p' })`
   - AniFam:
     ```js
     const dto = await anifam.getPlayback(episodeId, 'sub');
     const controller = new AniFamPlaybackController({
       resolveSource: (epId, srvId, track) => anifam.resolveIframeSource(epId, srvId, track),
       resolveRelativeUrl: (u) => anifam.resolveRelativeDomainUrl(u),
     });
     const state = await controller.loadPlaybackDto(dto);
     ```
2. **Sign a Proxy Token** for browser `<video>` / `hls.js`:
   ```js
   const token = proxy.signTarget({
     url: state.streamUrl,
     headers: state.mediaHeaders,
     mirrors: state.candidateUrls,
     unwrapTs: state.unwrapTs, // true for AniFam Mode 2 (resolved_hls)!
   });
   const proxyHlsUrl = `/api/proxy/hls?token=${encodeURIComponent(token)}`;
   ```
   > Why proxying is essential: Browsers forbid JavaScript from setting `Referer` / `User-Agent` headers, block cross-origin `.m3u8` / `.vtt` fetches lacking CORS headers, and `hls.js` cannot demux AniFam Mode 2 `.ts` segments that have fake `PNG`/`JPEG`/`GIF8`/`RIFF`/`BMP` headers prepended. `MediaProxy` solves all three transparently.

3. **Stream Downloads Directly to Users Without Server Disk Storage**:
   ```js
   const { stream, meta, done } = await createHlsDownloadStream({
     playlistUrl: state.streamUrl,
     preferredQuality: '1080p',
     headers: state.mediaHeaders,
     mirrorUrls: state.candidateUrls,
     concurrency: 16,
     unwrapTs: state.unwrapTs,
   });
   res.setHeader('Content-Type', 'video/mp4');
   res.setHeader('Content-Disposition', `attachment; filename="episode-${meta.selectedQuality}.mp4"`);
   stream.pipe(res);
   await done;
   ```

## 3. Frontend Integration (Vanilla JS or React)

### Vanilla JS / Any Website

Include `hls.js` plus `public/js/site-player.js` and `public/js/web-downloader.js`:

```html
<video id="player" controls playsinline></video>
<iframe id="embed" hidden></iframe>
<script src="https://cdn.jsdelivr.net/npm/hls.js@1.5.17/dist/hls.min.js"></script>
<script type="module">
  import { AnimeSitePlayer } from '/js/site-player.js';
  import { WebEpisodeDownloader } from '/js/web-downloader.js';

  const player = new AnimeSitePlayer({
    videoEl: document.getElementById('player'),
    iframeEl: document.getElementById('embed'),
    onSkipCue: (cue) => console.log('Skip cue:', cue),
  });

  await player.playAniFam(12345, { track: 'sub' });
  // Or MiruDL:
  // await player.playMiruDL('ep-987', { lang: 'jpn', quality: '720p' });

  const downloader = new WebEpisodeDownloader();
  downloader.triggerServerDownload({
    provider: 'anifam',
    episodeId: 12345,
    quality: '1080p',
    title: 'Episode-1',
  });
</script>
```

## 4. Production Security Checklist

1. **Set a strong `PROXY_SECRET`** (`openssl rand -hex 32`) in `.env` and set **`PROXY_ALLOW_UNSIGNED_DEV=false`** in production so `/api/proxy/*` and `/api/download` only accept HMAC-signed tokens generated by your backend (preventing open SSRF proxying).
2. **Keep Kyoto credentials & AniFam tokens server-side**: Never ship `KYOTO_RAW_KEY`, `KYOTO_CERT`, or `ANIFAM_BEARER_TOKEN` to browser bundles.
3. **Honor `403` entitlement responses**: When AniFam returns `status: 'entitlement_required'`, prompt the user to sign in rather than spinning through failover servers.
4. **Sandbox Mode 3 `<iframe>` embeds**: Always keep `sandbox="allow-scripts allow-same-origin allow-presentation allow-forms"` on the fallback iframe element so embed ads cannot hijack `window.top`.
